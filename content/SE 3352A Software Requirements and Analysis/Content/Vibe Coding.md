**Vibe coding** means describing the behaviour you want to an AI coding assistant instead of designing every class, API and UI component up front. You generate a working version, run it, and refine it iteratively.

It's effective for rapid [[Prototyping]] because the goal isn't production-quality code. The goal is to make an idea tangible quickly enough to test it with users or stakeholders. *e.g. a functional "SmartLearn" LMS prototype built in Replit.*

> [!warning] Proof of concept only
> - The generated code isn't reliable enough for production without **significant re-engineering**.
> - If you're worried about the privacy of your data or ideas, don't send them to an LLM unless there's a **reliable privacy agreement**.
