A **high-fidelity (hi-fi) prototype** is built with software tools and looks like a working software product. Compare the [[Low-Fidelity Prototype]].

It can be:
- a **presentation prototype**: non-functional, it looks real but doesn't work. *e.g. an LMS dashboard designed in Figma.*
- built with a **content management system**
- **functional**, built in your organization's programming language(s), or quickly via [[Vibe Coding]]
